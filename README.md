# GIFTED: The Game — Битва куполов

Карточная игра для экосистемы токена GIFTED (TON).

**Состояние: первичный импорт завершён частично.** Исходники и ключевая документация загружены; новые 45 PNG из `Decks.zip` / `Locations.zip` ещё не перенесены в GitHub. Текущий `index.html` — оригинальный прототип со старыми встроенными изображениями, а **не** исправленная версия с новой графикой.

## Структура
- [index.html](index.html) — временный браузерный прототип.
- [docs/gifted-brief.md](docs/gifted-brief.md) — решения и ограничения.
- [docs/gifted-cards.md](docs/gifted-cards.md) — карты и локации.
- [docs/art-prompts.md](docs/art-prompts.md) — промпты новых иллюстраций.
- [docs/gifted-domes-source-lite.html](docs/gifted-domes-source-lite.html) — лёгкий исходный HTML.
- [legacy/gifted-domes-game.html](legacy/gifted-domes-game.html) — исходный полный HTML.
- [docs/WORK_HANDOFF.md](docs/WORK_HANDOFF.md) — **начинать работу здесь**.
- [assets/README.md](assets/README.md) — перечень отсутствующих изображений.

## Принципы
Не менять токеномику GIFTED; награды из выручки игры; без pay-to-win. Изменения механик согласовывать с геймдизайнером. После изменения карт обновлять docs/gifted-cards.md. Изменения через ветки и PR.

После настройки GitHub Pages ожидаемый адрес: https://fpserg.github.io/gifted-the-game/ — публикация пока не подтверждена.
