# Переход на Claude Code
После утверждения и включения данного PR Claude Code заменяет Builders Guild как основной исполнитель. ChatGPT остаётся продуктовым архитектором; Product Owner утверждает решения и публикацию. Независимый Inspector не является исполнителем проверяемого изменения. Действующие требования AGENTS.md и DEVELOPMENT_PROTOCOL.md сохраняются; указания о конкретных моделях и чатах Builders Guild заменяются выбором Claude Code. Никакая автоматизация merge не активируется. Предложения ORCHESTRATOR_POLICY.md и PR #32 не становятся действующими от этого перехода.
## Очередь
Architect создаёт Issue с явным статусом READY, приоритетом, продуктовым разрешением, scope, критериями приёмки, риском и зависимостями. Claude проверяет актуальный main и открытые PR, не дублирует работу. Приоритет P0 выше P1 выше P2; при равенстве старшая задача первая. При неоднозначности — BLOCKED. Отчёт и PR привязаны к Issue. После независимой проверки и разрешения владельца публикация осуществляется только разрешённым способом без обхода защиты.
## Первичная настройка
Подключить Claude Code к репозиторию fpserg/gifted-the-game с минимально необходимыми правами на чтение, ветки и PR. Не выдавать административные права, не отключать защиту main. Проверить доступ чтением CLAUDE.md и списка задач. Не передавать токены в чат или git.
## Первые шаги
Проверить открытые PR #28, #30, #32; не сливать автоматически. Стабилизация тестов предшествует изменениям правил. Новые игровые изменения требуют отдельной READY задачи и утверждения Product Owner.
