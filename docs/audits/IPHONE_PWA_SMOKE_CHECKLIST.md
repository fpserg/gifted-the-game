# GIFTED — iPhone PWA Smoke Checklist

**Цель:** за 15–25 минут проверить минимальную пригодность альфы для 10–20 закрытых тестировщиков. Отметь каждое поле и приложи скриншот/видео при сбое. До исправления F-01 из alpha audit считать PWA/offline release gate открытым.

## 1. Чистый запуск и заставка
- [ ] Открой https://fpserg.github.io/gifted-the-game/ в Safari (онлайн); дождись полной загрузки.
- [ ] Кнопка **ИГРА** слева — синий/фиолетовый звёздный медальон, золотая надпись и окантовка, без наложенного текста.
- [ ] Кнопка **ОБУЧЕНИЕ** справа — зелёный звёздный медальон, золотая надпись и окантовка, **без внешнего зелёного/бирюзового кольца**.
- [ ] Кнопки одного размера, ничего не обрезано, обе нажимаются с первого тапа.
- [ ] При высоте экрана сверху/снизу надписи и кнопки не закрыты вырезом камеры, статус-баром или индикатором Home.

## 2. Обычная игра
- [ ] **ИГРА → выбор героя → бой**; выбери любого героя.
- [ ] В руке видны изображения, стоимость и сила; тап карты + локации работает.
- [ ] Верни выложенную карту в руку; стоимость энергии восстановилась.
- [ ] Попробуй перетащить карту вверх к локации, затем прокрутить руку горизонтальным свайпом.
- [ ] Нажми **Меню → Продолжить игру** — партия и энергия сохранились.
- [ ] Нажми **Меню → Выйти в меню** — видна заставка; можно начать новую партию.
- [ ] Заверши **все шесть ходов**; дождись результата примерно через 700 мс после окончания раскрытия.
- [ ] На экране результата попробуй **Ещё партию**, **Сменить героя**, **Главное меню**.
- [ ] В фазе раскрытия повторный тап «Завершить ход» не запускает второе раскрытие; выход в меню во время раскрытия недоступен.

## 3. Обучение
- [ ] **ОБУЧЕНИЕ → Первая битва → Начать обучение**.
- [ ] Попробуй выбрать неправильную карту и локацию — сценарий не ломается.
- [ ] Ход 1: Подарочный ящик в Кузню → вернуть карту → выложить снова → завершить ход.
- [ ] Пройди все 6 ходов по подсветке и нажимай «Продолжить» между ними.
- [ ] Финал: победа **2:1**; доступны повтор обучения, обычная игра, главное меню.
- [ ] Начни обучение заново; посередине открой подтверждение выхода, **отмени**, затем **подтверди** выход. В обычную игру можно войти после обучения.

## 4. PWA и обновление
- [ ] Safari → Поделиться → На экран «Домой»; запусти установленную **Game of Gifts** с иконки.
- [ ] Проверь **390×844 или 393×852** (укажи фактическое разрешение: ______); по возможности проверь 375×812 / 430×932.
- [ ] Поверни iPhone горизонтально: стол, рука, нижняя кнопка, подсказки и медальоны остаются доступными.
- [ ] Закрой PWA полностью и запусти вновь — обе кнопки и игра загружаются.
- [ ] После обновления сайта повторно открой установленную PWA онлайн, закрой, открой вновь; не вернулись старые CSS-кнопки / зелёный ободок.
- [ ] После успешного онлайн-запуска включи Авиарежим (убедись, что Wi‑Fi отключён), закрой и снова открой PWA: сохранённый интерфейс доступен. Затем верни сеть.
- [ ] Если возникает временная ошибка загрузки, проверь повторный запуск и восстановление после возврата сети; **не удаляй PWA до фиксации ошибки**.
